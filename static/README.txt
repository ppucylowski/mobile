ADHD Planner — static HTML edition

Open index.html directly in a browser. It contains all HTML, CSS, and JavaScript;
there are no dependencies, build commands, or external assets.

Hosting: upload index.html to the public root of any static host. Navigation uses
URL hashes, so no server redirects are needed. Serve with HTTPS for deployment.

Task completion is stored locally in the browser when storage is available.
It is not synchronized between devices. Settings can reset the example tasks.
The schedule is illustrative data, not a live calendar.

The Expo project is retained separately in the repository. This static edition
is independent of it. Expo widgets and native SQLite would require a separate
native implementation; they are not provided by this HTML file.
